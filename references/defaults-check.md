# 套路清单：写完才读

这一页列的是语言模型写视觉小说时最顺手的选择。每写完一样东西再读：构思的 6 个候选（`ideation.md` 第 3 步）、剧本 v0、每一章（validate 过了以后）、封面、配乐、审读时。写之前读，它会变成灵感，正好反过来。

命中一条不等于错。问一句：这个是这个故事非要不可的，还是因为它最顺手？顺手的换掉，换成从本作构思的起点里长出来的东西（见最后一节「怎么换」）。一个构思命中 3 条以上，换一个构思。

## 钩子和设定

- 用倒计时、「最后 N 天」「N 天后……」当钩子；每天报一次还剩几天
- 某个东西即将结束当外部压力：最后一届、要拆了、要关门、要废部、要搬走、要转学
- 失忆，或「每隔一段时间记忆被清空」
- 时间循环只当噱头，循环规则没有参与解谜
- 「一个普通人，被卷进非日常」

## 人物

- 原型 + 一个可爱的小反差（强势的人怕小东西，冷淡的人偷偷做手工）
- 两个重点角色一动一静、一个往前冲一个原地不动，当成差异化
- 机器人、AI、人偶「学会了感情」；结局时自称变了
- 成长标记 = 一句口癖、一个称呼、一句一直说不出口的话，在结局时变了或说出口了
- 秘密 = 一段自责的往事，结局时被原谅或自己放下
- 主角有一项特殊的感官或手艺，专门用来「听见 / 看见」别人的心事
- 主角有一句逃避用的口头禅，最后说不出口了
- 嘴硬心软的长辈配角，负责推主角一把，结局时留下一句话或一样东西
- 重点角色都是两个字的文艺名，各配一个代表色

## 物件和伏笔

- 怀旧物件当伏笔：信、明信片、磁带、收音机、旧照片、怀表、秒表、日记
- 一首只有半首的歌、一句没说完的话，高潮时补完
- 同一个物件在三条线里都是关键

## 情节

- 一场波及所有人的意外（停电、暴雨、断网），逼主角在两个人之间二选一
- 定线的选择是一个限时选择
- 高潮是唱一首歌、说出那句话、冲过终点
- 告白在夕阳的屋顶、天台、观景台
- 解法是「TA 一直在那里等」
- 低谷失去的是一班车、一份工作、一次机会

## 结构

- 共通线 + 两三个可攻略角色的个人线 + 每条线 Good / Normal + 一个 Bad，共 5 个结局
- 每条个人线都是同一个节拍顺序
- 所有选择都是「选一句话说」

## 语言

- 「……」开头的句子到处都是
- 每个角色都用短句、句号、停顿，声音被同一种「含蓄」拉平
- 「不是 X，而是 Y」；旁白最后一句升华
- 角色说出主题句

## 画面和声音

- 夕阳色调、樱花、星空当情绪按钮
- 封面：放射光 + 大太阳 + 两人并排
- 曲目照「日常 / 搞笑 / 恋爱 / 平静 / 悲伤 / 紧张 + 每人一首」排
- UI 主题色照抄 starter

## 怎么换

- 回到构思选中的那个起点（手艺、地方、关系、问题、玩法、讲法），从它里面找：只有它才会带出来的麻烦、规则、物件、说法
- 从人物的「缺」里找：TA 缺的那样东西，在这个世界里具体长什么样
- 别每部都从同一种起点找（比如每部都是一门手艺），那又是一个新模板
- 换完再问一遍：这个东西换到别的故事里还成立吗？成立就还是太通用
