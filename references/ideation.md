# 构思：每个游戏从零长出来

语言模型每一步都挑最可能的那个选项。写在 skill 里的任何具体例子、默认值，都会变成「最可能」：例子里是什么题材，下一个游戏就是什么题材；例子里的角色是什么样，下一个游戏的角色就差不多。同一个人连做几个游戏，会一个比一个像。

所以这个 skill 不给剧情、人物、场景、台词的样例，格式示范只用占位符。这一页规定构思怎么做，目标是每个游戏的题材、结构、人物、画面、声音都从它自己的构思里长出来。

## 顺序（不能换）

1. 列约束
2. 发散：6 个候选
3. 去套路：读 `defaults-check.md`
4. 去重：比旧作指纹
5. 收敛：给用户 3 个

第 2 步之前不读 `defaults-check.md`、不看以前的游戏、不进作品目录（那里的 `CLAUDE.md`、README 会把旧作的摘要带进来）：先看了，脑子里就有了答案，候选会往那里靠。候选写在会话的 scratchpad 里，项目目录等选定了再建。

## 1. 列约束

- 用户说出口的是硬约束：题材词、风格词、长度、平台、年龄、要不要恋爱
- 用户没说的全是自由维度，不填默认值。用户只说了一个风格词，这个词只管画面和气氛，题材、结构、人物照样要发散
- 写下来：`硬约束：…` `自由：…`

## 2. 发散：6 个候选

每个候选从一个不同的起点长出来，6 个起点各用一次：

| 起点 | 从哪长 |
|---|---|
| 手艺 | 一个具体的行当：这个人每天手上做什么、用什么工具、行内有什么规矩和黑话 |
| 地方 | 一个地方独有的规则或物件：只有在这里才会发生的事 |
| 关系 | 两个人之间一种具体的张力：欠着什么、瞒着什么、争什么 |
| 问题 | 一个想让玩家自己回答的问题，没有标准答案 |
| 玩法 | 玩家在游戏里做的那件事，「选一句话说」之外的：给出什么、相信谁、记住什么、交换什么 |
| 讲法 | 叙事形式上的一个限制：时间、视角、顺序、媒介 |

每个候选写五行：

- 一句话故事：只用这个故事才有的名词；把名词换成别的题材的，句子就不成立了
- 玩家做什么：一局里反复做的那个决定是什么，它为什么难选
- 为什么是视觉小说：靠对话、人物、选择推进；没有动作戏
- 画面：3–6 个场景撑得住；代码画得出来（看 `engine-notes.md` 引擎能画什么）
- 指纹：下面那张表的每一轴填一个值

6 个候选两两之间，指纹至少 5 轴不同。

## 3. 去套路

现在读 `defaults-check.md`，6 个候选逐条对：

- 命中一条就问：这个设定是这个故事非要不可的，还是因为它最顺手？顺手的换掉，换成从这个候选的起点里长出来的东西
- 一个候选命中 3 条以上，整个淘汰

## 4. 去重：比旧作

- 作品目录（游戏项目的上一级）有 `FINGERPRINTS.md` 就读：以前每个游戏一行指纹。只读这一个文件，作品目录里别的文件（`CLAUDE.md`、各游戏的 README、剧本）这时候也不读
- 每个候选和每部旧作逐轴比：
  - 任何一部旧作，至少 6 轴不同
  - 和最近一部比，「钩子」「结构」「高潮」三轴都要不同
- 不过线的改到过线，或者淘汰

## 5. 收敛

- 从剩下的里挑 3 个给用户，每个附：一句话故事、玩家做什么、指纹、和最像的旧作差在哪、风险（哪里难画、哪里选择可能没分量）
- 用户说「你看着办」时自己挑一个，理由写进 LOG
- 选定后建项目目录（SKILL「目录」），候选从 scratchpad 拷进 `work/` 留底；指纹写进 `剧本_v0.md` 开头；后面每一步（人设、结构、美术、配乐、封面）都对照它，别做着做着滑回顺手的写法

## 指纹

| 轴 | 填什么 |
|---|---|
| 类型 | 一个词 |
| 时代和地点 | 一个词组 |
| 钩子 | 推着玩家往下看的是什么：秘密 / 目标 / 关系 / 谜 / 处境 / 期限 |
| 结构 | `genres.md` 里的哪一种，或自定 |
| 重点角色数 | 可攻略或主要对手戏的角色几个 |
| 主角 | A / B / C 型（`character-writing.md` §1.3），以及主角在故事里靠什么动起来：一个本事 / 一个处境 / 一个秘密 / 一个目标 |
| 变化落在哪 | 结局时人物的变化落在哪（也可以不变）：一个行动 / 一个选择 / 一段关系 / 一句话 / 一个习惯 |
| 高潮 | 最后那一下靠什么：一个限时选择 / 一件证据 / 一次放弃 / 一次坦白 / 一个揭开的真相 / 别的 |
| 收尾 | 结局的形状：分好坏 / 分方向 / 一个结局多种余味 / 开放 |
| 主要互动 | 玩家主要在做什么：分好感 / 找线索 / 分配 / 记住 / 别的 |
| 画面 | 主色 + 封面的构图一句话 |
| 声音 | 配乐的乐器和情绪基调一句话 |

交付时把本作这一行追加进作品目录的 `FINGERPRINTS.md`（没有就新建，表头照上面）。`node tools/fingerprint.js` 会从剧本里读出结构上的数字，和同目录下的旧作比，结构撞了会提醒。
